# Black Jack C# Projekt

## Projektbeskrivning En kort text om vad projektet gör.
Vi bygger ett Black Jack spel i C# som körs i konsolen.

Spelet går ut på att spelaren spelar mot en dealer och försöker komma så nära 21 poäng som möjligt utan att gå över.

## Instruktioner för att köra projektet
Öppna projektet i Visual Studio.

Öppna lösningsfilen (.sln).

Starta programmet med Ctrl + F5.

Följ instruktionerna som visas i konsolen.

## Hur spelet körs
När spelet startar får spelaren och dealern två kort var.

Spelaren börjar och får välja om den vill ta ett nytt kort (Hit) eller stanna (Stand).

Om spelaren får över 21 poäng förlorar den direkt.

När spelaren har stannat är det dealerns tur. Dealern måste dra kort tills den har minst 17 poäng.

Om dealern får över 21 poäng förlorar dealern.

När båda är klara jämförs poängen. Den som är närmast 21 utan att gå över vinner.

Om spelaren och dealern har lika många poäng vinner dealern.

## Vilken fil som startar programmet
Programmet startar från Program.cs, där metoden Main() finns.
